The mockup is live — open a block, close a window. It is also a standalone page at pages/c-hub.html.

Design proposal

The hub, and what is behind each block

/information holds six things — what the list is and where everything on the site lives, the guidelines, two legends, the FAQ, who to talk to, and the API — and today it stacks the four it has as cards of roughly equal size. The Pending List legend, nine rows of icons, is given a full-width card; the guidelines, thirteen sections across five groups, are given a 600 px window to be read through. Weight on the page is the opposite of weight in the content.

This rebuilds it as a hub of six faces. Each carries a label, a name, one sentence and the size of what is behind it — “14 questions”, “9 pages”, “19 marks”, “9 endpoints” — and every one of them opens the same reader over the page. The hero says what the list is, offers the full version at the end of the sentence, and puts one search field under it. The blocks run in the order people arrive wanting them: the FAQ first, the navigation beside it, the guidelines three rows down the left, and the reference, staff and API stacked to their right. At 1440 px the whole page is one screen and a nudge.

It is built from css/ull-v2.css, the component layer the rest of the site was rebuilt on, so it introduces no new card, heading or button. The copy for the sections that did not exist — what the list is, the navigation, the FAQ, the API — is drafted in design/information/copy.md, and the mockup renders that draft rather than lorem.

Scope
Desktop only, as asked. The mobile route /mobile/info is untouched.
Sections
The five agreed, plus navigation and API. Submitting and points are FAQ entries; the glossary is a guidelines section.
New data
None. Editors come from data/_editors.json, guidelines from js/_guidelines.js, endpoints from worker/worker.js.
Dropped
A. Shelf, B. Manual, D. Document and E. Tiles. All four are in git history if any is wanted back.

What is wrong with the page today

  1. 01The legends outweigh the guidelines. .info-cards is a 1fr 1fr grid and the Pending legend is given grid-column: 1 / -1 by an inline style, so nine icon rows occupy the full page width while the entire rulebook is read through a max-height: 600px pane below it.
  2. 02The guidelines scroll inside a page that scrolls. .info-guidelines-content is its own scroll container inside .info-page, so the wheel does one thing or the other depending on where the pointer is. Information.js carries an IntersectionObserver whose only job is to switch that inner overflow-y on and off — a workaround for a nesting that does not need to exist.
  3. 03The colouring legend redraws a component the site already has. Ten swatches are written as inline style="background:#5599ff", and those ten hex values are the same scale as .u-pill--blue … .u-pill--done in css/ull-v2.css. The legend for a colour system should be drawn with the colour system, or it will drift from it.
  4. 04Nothing tells a first-time visitor where anything is. The hero defines the list in four lines and the next thing on the page is a list of editors. There is no map of the site, and no answer to the questions that bring people here — how to submit, how points are earned — anywhere on it.
  5. 05The card hover from the pending page is here too. .info-guidelines:hover applies transform: scale(1.006), which nudges the layout under the pointer. The same tic was removed from the other pages in the last pass.
